# Mods do Habel

## faixa-uso-cache
Uma faixa fina em cima da caixa de texto do Claude. Mostra quanto do uso da semana ainda resta (o numero real que o app recebe) e se o cache da conversa esta quente. Depois de 1 hora sem mensagem a faixa fica vermelha: "Cache Frio, a proxima mensagem rele tudo".

Instalar: `/plugin install faixa-uso-cache --marketplace Reifog/claude-mods`
